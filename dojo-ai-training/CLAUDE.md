# CLAUDE.md

Markdown notes and exercises from the AI training. There is no code and there is no build here.

## Layout

- `docs/`: what the user learned. Summaries and reusable material, such as course notes.
- `exercises/day-N/`: hands-on work, one folder per course day. File names and structure inside a day folder depend on the exercise. Exercises about code point at `../task-tracker`.
- `README.md`: index of docs and exercises. Update its tables when you add, rename or move a file.

Links between files are relative. When you rename or move a file, update every link to it. In-repo code links use the `path/file.ts#L37-L45` form.
